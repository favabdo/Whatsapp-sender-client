WhatsApp Sender - Client build
==============================

Run:
1) Install Google Chrome.
2) Install ODBC Driver 17 for SQL Server.
3) Start: Start WhatsApp Sender.bat
   or: start_silent.vbs
   or: WhatsApp Sender.exe if present.
4) First launch: enter SQL Server settings, then login with a DB user.

Notes:
- No source code in this package.
- users.key is required to decrypt user passwords - do not delete it.
- SQL settings are stored locally (sql_settings.bin).
- Session data: wa_chrome_profile / uploads.
